首个公开版本，服务端与电视端功能完整可用。

### 电视端
- 歌曲列表 + 遥控器上下选歌、OK 打开
- 一屏左右各一张琴谱（对应谱本左右页）
- 下/右键下一屏，上/左键上一屏，BACK 返回曲库，MENU 改服务器地址
- 阅读页保持屏幕常亮、隐藏系统栏
- 无广告 SDK、无统计 SDK、无 WebView，仅访问自建曲库
- 原生 Java，APK 95KB，1GB 内存的电视盒子可流畅运行

### 服务端
- Express 曲库服务：新建歌曲、批量上传琴谱、追加、删除
- 网页管理后台，顶部显示电视端应填写的地址
- 支持 `BASE_PATH` 子路径部署（如 `https://example.com/guitar/`）
- 数据落盘为 `data/songs.json` + `data/uploads/`，备份目录即可

### 说明
- 安装包使用开发证书签名，供侧载测试；公开分发请自行替换签名
- 支持 JPG / PNG / WebP，单张 ≤ 20MB，每首最多 60 页
- 适配设备：MagicBox_M30_F（YunOS / Android 10，1920×1080，1GB RAM）
